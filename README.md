# Optimise B1 · Interactive English Studio

Независимый образовательный проект по предоставленному **Optimise Stars B1 Student’s Book**. Сайт не представляет Macmillan. Материал Workbook не добавлен. Работает статически на GitHub Pages; backend, аккаунт и ключи API не требуются.

## Содержание

В меню семь разделов: Starter (pp.6–9), Unit 1 (pp.10–19), Unit 2 (pp.20–29), Review 1–2 (pp.30–31), Unit 3 (pp.32–41), Unit 4 (pp.42–51), Review 3–4 (pp.52–53). Сохранены последовательность, оригинальные номера и тексты упражнений. Справочные и дополнительные карточки обозначены отдельно.

**Доступность раздела не означает полноту медиа.** Нет оригинальных видео, аудио3.01–3.07 и4.01–4.08. Зависимые от них задания сохраняют вопросы, но явно помечены и исключены из прогресса, автопроверки и наград. Текстовые задания listen-and-check можно выполнять письменно; отсутствующее аудио у них тоже подписано. Подробности: REPORT.md и страница Teacher→Coverage.

## Teacher Mode

Прежний код учителя сохранён. Кнопка Teacher включает режим в текущей вкладке. «Показать ответы» открывает отдельную панель; «Скрыть ответы» закрывает её. Ключ не вписывается в работу ученика и не начисляет прогресс. При возвращении в Student Mode панель очищается. Есть допустимые альтернативы, модели свободных ответов и пояснения.

Официальные ключи предоставлены для Starter, Units1–2 и Review1–2. Ключи Units3–4/Review3–4 составлены для платформы, отмечены «не из Teacher’s Book». Открытые ответы не проверяются по единственному образцу. Статический код скрывает учительские элементы в интерфейсе; исходники содержат ключи автопроверки.

## Возможности

- Matching, multiple choice/select, typing, sorting, word order, reading, listening, speaking с таймером, writing с подсчётом слов.
- Check / Hint / Try Again / Reset Exercise, переход к следующему заданию, Core Route / Extra Practice.
- Vocabulary Lab: переводы, контексты, карточки, matching, memory, набор слова, игры и интервальное повторение.
- Словарь и прогресс разделены по unit:word; выбранный юнит не подмешивает слова других тем.
- Аудиоплеер: пауза, скорость, перемотка. Все19предоставленных записей Starter/Units1–2 подключены.
- Локальные профили, прогресс, export JSON/CSV. Старые данные Optimise сохранены; чужие данные не импортируются.
- New Student / Reset All сбрасывает текущий профиль, таймеры, медиа, подсказки и режим учителя. Другие профили сохраняются.
- Клавиатурное управление, touch, адаптивная вёрстка и reduced motion.

## Публикация и переименование

Существующий репозиторий: https://github.com/0011nvg/panoramic-b1

Текущий адрес Pages: https://0011nvg.github.io/panoramic-b1/

Переименование репозитория требует GitHub Settings→General→Repository name→`optimise-b1`→Rename. Выполнить его через доступный файловый GitHub API нельзя; в браузере нет авторизованного входа. **Новый репозиторий не создавался.** После переименования проверьте Settings→Pages (`main`, root); ожидаемый адрес будет `https://0011nvg.github.io/optimise-b1/`. Этот будущий адрес не считается проверенным до переименования.

Все файлы используют относительные пути, внутренние маршруты — hash. Поэтому код не зависит от имени репозитория. Соль старого кода учителя оставлена для совместимости; она не является названием сайта.

## Разработка и проверки

`npm test` / `node tests/static.js` — структура, нумерация, схемы ответов, источники, assets, словарь, миграция и read-only teacher extraction.

`npm run dev` — статический preview. GitHub Pages не требует npm или сборки.

GitHub Actions запускает static и browser QA (375/820/1366px, все уроки, ключи, аудио, teacher/student, hint/retry, progress/reset). Локальный прогон static не означает успешный запуск CI: фактический результат записывается в отчёт.

`js/core.js`, `js/exercises.js`, `js/vocab.js` — storage, режимы, упражнения и тренажёры.
