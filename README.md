# Optimise Stars B1 · Interactive English Studio

Интерактивная платформа по учебнику **Optimise Stars B1** (Student’s Book). Статический сайт для GitHub Pages: без сервера, без сборки, все пути относительные.

**Готово полностью:** Starter (pp. 6–9) и Unit 1 “How we live” (pp. 10–19) + связанные страницы Grammar reference (pp. 136–138), Vocabulary reference (pp. 150–151), Writing reference (p. 159), Speaking reference (p. 164).
**Скоро:** Unit 2 – Unit 10 и Review-разделы — видны на карте курса с пометкой «Скоро», без уроков и заданий.

## Публикация
Settings → Pages → *Deploy from a branch* → `main` / `(root)`. Через 1–2 минуты сайт будет по адресу `https://0011nvg.github.io/panoramic-b1/`.
Страница закрыта от поисковиков (`noindex`), но репозиторий публичный — учитывайте права на материалы учебника.

## Что есть на сайте
- **Карта курса** на главной: Starter + 10 юнитов + Review; готовые разделы открываются, остальные помечены «Скоро».
- **Уроки в порядке учебника** с исходной нумерацией страниц и заданий (номер и `p.` на каждой карточке; поиск «13 4» = с. 13, упр. 4).
- **Форматы заданий:** ввод в пропуски, выбор в тексте, выпадающие варианты, сопоставление, распределение по группам, таблица соответствий, «верно / исправь», составление предложений по картинкам, поиск слов в тексте, аудирование, рисунок по описанию, план сочинения, письмо со счётчиком слов, говорение с таймером, чек-листы.
- **Проверка:** Check → подсветка, «почти верно» (орфография), Hint, Try Again. Правильные ответы ученик может открыть **только после своей попытки** (Show answers); после этого звёзды за задание не начисляются. Пояснения с ключом тоже открываются после первой проверки.
- **Свободные ответы** (устные задания, письмо, «true for you») система не проверяет: ученик отмечает выполнение, учитель видит образцы.
- **Аудио:** плеер с паузой, перемоткой ±5 с, ползунком и скоростью 0.75–1.25×.
- **Картинки учебника** рядом с заданиями, увеличиваются по нажатию; на картинке дома (p. 13) — номера ярлыков.
- **Словарь** (74 слова Starter и Unit 1) — карточки, Learn with Keks, интервальное повторение, сложные слова.
- **Прогресс, звёзды, XP, миссии уроков, самооценка «Can do?»**, работа над ошибками.

## Режим учителя
Кнопка **Teacher** в шапке → код учителя. В режиме учителя видны: кнопка «Ключ (учитель)», пометка источника ключа, образцы ответов (Teacher’s Book или подготовленные), методические заметки, вопросы ученика, комментарии, профили учеников, таблица аудио и соответствия учебнику (`#/coverage`).
- **Код:** работает прежний код учителя (хэш не менялся). Сменить — `tools/teacher-code.html` (инструкция `tools/teacher-code.md`).
- **Ограничение:** сайт статический, поэтому код скрывает материалы в интерфейсе, но ключи для автопроверки лежат в `js/data-*.js` и технически доступны тому, кто откроет код страницы. Для настоящей защиты нужен сервер с авторизацией (см. `tools/teacher-code.md`).

## Источники ключей
На каждой карточке в режиме учителя:
- **Ключ: Teacher’s Book** — ответ из присланного Teacher’s Book (Starter, Unit 1);
- **Teacher’s Book (suggested answers)** — в книге ответ дан как «suggested»;
- **подготовлен для платформы** — ответ составлен по тексту/фото (не официальный): образец абзаца Starter Ex. 3, образец статьи Unit 1 Ex. 7, ответ к Speaking Ex. 5;
- **свободные ответы** — в Teacher’s Book «Students’ own answers».

## Аудио
`audio/u1/1.01.mp3 … 1.06.mp3` — дорожки Unit 1 (присланные файлы `OPT2E_SB_B1_TRACK_1_01…06`, сверены по содержанию; перекодированы в 96 kbps mono для мобильного интернета).
Дорожки `TRACK_2_01…07` — это Unit 2 (2.01–2.07); подключатся вместе с Unit 2.
**Нет файлов Starter S.01–S.05** — задания работают, плеер показывает пометку. Чтобы подключить: положите файлы в `audio/starter/` под именами `S.01.mp3 … S.05.mp3` и в начале `js/data-starter.js` замените строку `const A = t => ({ track: t });` на `const A = t => ({ track: t, file: 'audio/starter/' + t + '.mp3' });`.

## Как добавить Unit N
1. Создайте `js/data-unitN.js` по образцу `js/data-unit1.js` (уроки `uN-1 … uN-8`, `uN-ref`).
2. В `js/course.js` у юнита: впишите `lessons: [...]`, поставьте `ready: true`, уберите `soon: true`.
3. Подключите файл в `index.html` после `data-unit1.js`; слова — в `js/data-vocab.js` с `lesson: 'uN-…'`; фото — в `assets/book/` и `js/data-visuals.js`; аудио — в `audio/uN/`.
4. `node tests/static.js` и `node tests/qa.js http://localhost:8765/`.

## Прогресс
Хранится в localStorage этого браузера, отдельно для каждого ученика (Teacher → Students). **Синхронизации между устройствами нет**; для переноса — Export JSON в My Progress. Прогресс прежнего сайта Panoramic хранится отдельно и сюда не попадает.
