# Код режима учителя

**Что сейчас.** В `js/core.js` хранится только хэш кода (`TUTOR_HASH`, `TUTOR_FNV`), сам код в репозитории не записан.
Хэш и «соль» `panoramic-b1:` оставлены прежними, поэтому **работает тот же код учителя, что был на сайте Panoramic B1**.

**Как поставить свой код (2 минуты).**
1. Откройте файл `tools/teacher-code.html` в браузере (двойной щелчок по скачанному файлу или по ссылке
   `https://<ваш-логин>.github.io/<репозиторий>/tools/teacher-code.html`).
2. Введите новый код (лучше 8+ символов, буквы и цифры) и нажмите «Получить строки».
3. В `js/core.js` замените строку `const TUTOR_HASH = '…', TUTOR_FNV = '…';` на строку из результата.
4. Сохраните (commit) — через 1–2 минуты GitHub Pages обновится. Старый код перестанет работать.

То же из терминала:
```
printf 'panoramic-b1:НОВЫЙКОД' | sha256sum          # → TUTOR_HASH
node -e "let h=2166136261;for(const c of 'panoramic-b1:НОВЫЙКОД'){h^=c.charCodeAt(0);h=Math.imul(h,16777619)>>>0}console.log(h.toString(16))"   # → TUTOR_FNV
```

**Ограничение (важно).** Сайт статический (GitHub Pages, без сервера). Код скрывает ключи и заметки в интерфейсе,
но ответы для автопроверки лежат в файлах `js/data-*.js` и технически доступны тому, кто откроет код страницы.
Это защита «от случайного подглядывания», а не защита данных.

**Если нужна настоящая защита:** учительские материалы (ключи, образцы, заметки) переносятся на сервер с входом
по логину — например, Supabase (бесплатный тариф: база + авторизация) или Cloudflare Worker с паролем.
Тогда в открытых файлах остаются только хэши ответов для автопроверки, а ключи выдаются сервером после входа учителя.
