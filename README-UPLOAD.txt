OPTIMISE B1 — ПУБЛИКАЦИЯ НА GITHUB PAGES

1. Распакуйте ZIP.
2. Загрузите всё содержимое архива в корень существующего репозитория (index.html должен быть сразу в корне).
3. В Settings → Pages выберите Deploy from a branch → main → /(root).
4. Дождитесь успешного pages build and deployment в Actions и откройте адрес Pages.

Новый репозиторий создавать не нужно. Для переименования существующего: Settings → General → Repository name → optimise-b1 → Rename. Пути относительные, код подходит для старого и нового имени.

Список недостающих исходных аудио/видео и статус проверок: REPORT.md.
Код учителя прежний. Инструкция: TEACHER-GUIDE.md.
Сайт статический, npm и backend для публикации не нужны.
