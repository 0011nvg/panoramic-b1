# Аудит и обновление — Panoramic B1 (31.10.2026)

## 1. Что было проверено
- **Содержание:** все 39 уроков (Entry E1–E12, Units 1–3 + GR + WB), 617 заданий, 226 слов. Автоскрипт проверил: каждый ключ принимает сам себя, индексы ответов в выборе/inline/match в пределах вариантов, нет дублей вариантов, пустых ключей, пробелов в ключах, повторов слов и непарных скобок; в словаре — у каждого слова есть перевод, транскрипция, определение, пример, и пример содержит само слово.
- **Проверка ответов:** 1 629 модульных проверок (`tests/answers.js`) + браузерные сценарии со свободным вводом.
- **Интерфейс:** 38 страниц на 1366 px и 375 px (touch), консоль, сетевые ошибки, горизонтальная прокрутка, все аудиофайлы.

## 2. Найденные и исправленные ошибки
| Где | Ошибка | Исправление |
|---|---|---|
| Все задания с автопроверкой | После проверки в строке результата печаталось слово **«null»** («Excellent! Everything is correct. null») | Пустые элементы больше не выводятся; автотест следит, чтобы «null» не появлялся |
| Проверка ответов | Правильные варианты записи считались ошибкой: *he’s = he has*, *I’d = I had*, *organized / organised*, *face to face / face-to-face*, *five / 5*, *twenty-four / 24*, *Mr / Mr.*, «?!» в конце | Принимаются симметрично (для ответа и ключа). Форма слова, время и порядок слов проверяются строго, как раньше. Тест подтверждает, что ни один ответ из соседнего пропуска не стал «правильным» |
| Проверка ответов | *didnt* вместо *didn’t* просто «неверно» | Подсвечивается оранжевым «почти верно» — ученик видит, что ошибка только в апострофе |
| Словарь | Карточка «Not yet» засчитывалась как ошибка → новое слово сразу попадало в Difficult Words | «Not yet» = слово новое, а не ошибка |
| Словарь | Задание на узнавание отодвигало уже назначенное повторение | Узнавание больше не сдвигает расписание интервального повторения |
| Словарь (*environmentally friendly*) | Пример не содержал самого слова (*eco-friendly*) — нельзя тренировать употребление | Пример: *Social media is an environmentally friendly way to promote protests.* (*eco-friendly* остаётся допустимым вариантом) |
| Keks Blitz | XP можно было «нафармить» бесконечными раундами | XP только за первые 3 раунда в день |

Ошибок в ключах Units 1–3 не найдено. Опечатки ключа Entry Book, найденные ранее, по-прежнему отмечены в Tutor note (E2 с. 8 упр. 5, E12 с. 48 упр. 13, E9 с. 33 упр. 1).

## 4. Что появилось
**Игровой слой** (`js/game.js`) — каждая награда привязана к учебному действию:
- ★ / ★★ / ★★★ за каждое задание с проверкой (50 / 80 / 100 %, лучшая попытка);
- XP за первое выполнение, за исправление ошибок до 100 % (бонус), за слова, вспомненные по памяти с интервалом, за миссии; повтор решённого задания XP не даёт;
- 9 уровней (Newcomer → B1 Legend), серия дней 🔥;
- **3 миссии в каждом уроке**, собранные из его же заданий: Core route, Sharp eye (★★★ в 3 заданиях), Word keeper (6 слов урока по памяти);
- 12 значков (First step, Bug hunter, Boss slayer, Living dictionary…);
- экран «Lesson complete»: звёзды, миссии, что исправить, следующий урок.

**Кекс** (`js/keks.js`) — участник занятия, а не украшение:
- один раз объясняет каждый новый тип задания (по-русски, коротко);
- радуется 100 %, хвалит за исправленные ошибки, после ошибки поддерживает и предлагает подсказку, если она есть;
- сообщает о миссиях, значках, новом уровне;
- иногда (не чаще раза в 15 минут) предлагает **бонус-раунд**: 5 сложных / пора-повторить слов по памяти;
- по нажатию — «что дальше»: слова на повторение, сложные слова, задания с ошибками;
- не мешает: реплика закрывается при любом действии ученика, на телефоне кот прячется при вводе текста, есть «Тихий режим», в режиме доски скрыт.

**Слова** (`js/vocab.js`):
- **Learn with Keks** — умная сессия: 8 слов (сначала сложные и «пора повторить») × 3 шага: узнать → употребить в контексте → вспомнить и написать;
- **Right Word, Right Place** — выбрать слово для нового предложения (сочетаемость, контекст);
- **Sentence Builder** — собрать пример со словом из частей;
- **Keks Blitz** — 60 секунд на узнавание, серии умножают очки.

**Ученику:** главная-дашборд «Сегодня» (уровень, продолжить с нужного задания, слова, работа над ошибками), путь урока Start → Practice → Train → Apply → Review в навигации, очередь «Mistake hunt» в Revision.

**Преподавателю:** поиск упражнения (кнопка 🔍 или клавиша «/»: «13 4» = с. 13 упр. 4, или слова — «question tags»); **Board mode** — крупный шрифт для интерактивной доски, без XP, звёзд и кота.
