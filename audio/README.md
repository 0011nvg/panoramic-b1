# Аудио

Положите сюда файлы учебника (mp3/m4a) и впишите путь в `js/data-unit1.js` → `audio.file`.

| Трек | Задание | Ожидаемый файл |
|---|---|---|
| 01 | Unit 1 opener, Ex.1 p.11 (видео/аудио) | audio/01.mp3 |
| 02 | Unit 1 opener, Ex.2 p.11 | audio/02.mp3 |
| 03 | 1.1 Ex.4 p.12 | audio/03.mp3 |
| 04 | 1.1 Ex.5 p.12 | audio/04.mp3 |
| 05 | 1.1 Ex.6 p.12 | audio/05.mp3 |

Пример: `audio: { track: '03', file: 'audio/03.mp3' }`.
Ключ к упражнению пишется в `inner.answers` / `a` у вопроса (см. README.md в корне).
Имена файлов — латиницей, без пробелов (GitHub Pages чувствителен к регистру).
