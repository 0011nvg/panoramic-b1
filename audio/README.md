# Аудио

Файлы Student Book Panoramic B1. Имя файла = номер трека (`audio/NN.mp3`), путь вписывается в поле `audio.file` в `js/data-unitN.js`.
Если у трека `file: null`, на сайте честная заглушка без кнопок воспроизведения.
