# Optimise B1 — руководство преподавателю

1. Выберите раздел на Course map, затем урок. Номер и печатная страница учебника есть на каждой карточке.
2. Core Route скрывает Extra Practice; исходные номера и порядок не меняются. Распределяйте материал юнита на несколько занятий.
3. Включите Teacher прежним кодом. У упражнения нажмите «Показать ответы». Ключи открываются отдельно от полей ученика; повторное нажатие скрывает их.
4. Teacher’s Book означает предоставленный официальный ключ. «Подготовлен для платформы» означает составленный, не официальный ответ. Образец Speaking/Writing допускает другие содержательные варианты. Оценивайте смысл, уместность и язык; сайт не выставляет ему автоматическое correct/incorrect.
5. При выходе в Student Mode учительская панель очищается. Ответы ученика сохраняются.
6. В заданиях с доступной записью используйте Play, скорость и ±5s. Без обязательной записи карточка явно помечена и не оценивается. Нет аудио3.01–3.07,4.01–4.08 и исходных видео. Не заменяйте их аудио другого раздела.
7. В Vocabulary Lab выбирайте юнит/урок. Повторяющиеся слова с разными значениями хранятся отдельно; All words — явно общий набор. Переводы и тренировочные контексты составлены для платформы.
8. Для следующего ученика сначала при необходимости Export JSON/CSV, затем New Student / Reset All. Сброс очищает текущий профиль и состояние урока, останавливает таймеры/медиа и закрывает Teacher. Другие профили сохраняются.

Прогресс находится только в браузере на этом устройстве. После переименования GitHub-репозитория origin остаётся тем же, поэтому локальные данные доступны. Код учителя — управление отображением статического сайта, не серверная защита исходников.
